# Product

## Register

product

## Platform

macOS desktop app built with Electron, with companion CLI and SDK surfaces

## Users

Software developers who run one or more terminal coding agents across local and remote git worktrees. They work from the desktop app, shell scripts, the Superset CLI, SDK integrations, and agent-driven automation, often moving between those surfaces during the same task.

## Product Purpose

Superset gives developers one place to create isolated workspaces, launch and monitor coding agents, review their changes, and take over directly when needed. Success means developers can run more work in parallel without losing visibility, control, or confidence in what each agent is doing.

## Positioning

Superset is the agent-agnostic control surface for local, worktree-based software development.

## Brand Personality

Capable, direct, and energetic. The product should feel fast and powerful while remaining transparent about the commands, machines, repositories, and agent settings it controls.

## Anti-references

Avoid hidden or magical behavior, settings that differ silently between surfaces, decorative dashboard patterns, and abstractions that conceal the underlying developer workflow. Familiar terminal, editor, and project-management conventions should remain recognizable.

## Design Principles

- Make consequential launch behavior explicit and inspectable.
- Keep desktop, CLI, SDK, and automation semantics consistent.
- Preserve the power and vocabulary of each underlying agent.
- Favor compact, familiar controls that keep developers in flow.
- Surface actionable failures before creating partial work.

## Accessibility & Inclusion

Core workflows must remain keyboard accessible with visible focus, clear labels, sufficient contrast, and status or error messages that do not depend on color alone. Motion should communicate state and respect reduced-motion preferences.
